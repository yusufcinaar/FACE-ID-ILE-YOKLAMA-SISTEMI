# Fotoğraflar

Kullanım iznin olan, tek yüz içeren fotoğrafları bu klasöre koy.
Dosya adı öğrenci adı olarak kullanılır: `Örnek Öğrenci.jpg`.
JPG, JPEG ve PNG desteklenir. Aynı isim için tek dosya kullan.

Fotoğraflar Git tarafından yok sayılır. Uygulama bunları yalnızca bilgisayarında işler.
Fotoğraf eklemeden denemek için `python FACE_ID/deneme.py --demo` komutunu kullanabilirsin.

Önceki sürümde takip edilen fotoğraflar bu sürümden çıkarıldı. Eski commit'lerdeki kopyalar Git geçmişinde kalır.
